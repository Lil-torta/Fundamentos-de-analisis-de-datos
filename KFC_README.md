# Analisis de Ventas Globales - KFC (2018-2024)

## Descripcion

Proyecto de practica simulando un encargo real: de un analisis de datos de ventas globales para el equipo de estrategas de KFC, el cual sirve para identificar patrones de mercado y oprtunidades de mejorar ventas.

## Objetivos

Entender el desempeno de venta por pais del 2018 al 2024, evaluando el impacto del marketing relacionado con las ventas y buscar cuales son las estaciones o meses con mas ventas, y mejorar la toma de deciciones informadas.

## Dataset

-**fuente:** Kaggle(https://www.kaggle.com/datasets/usman44m/kfc-global-sales-dataset-20182024)
-**Tamano:** 8000 filas y 7 columnas
-**Columnas:** Year, Month, Country, Branch_ID, Sales, Customers, Marketing_Spend
-**Periodo:** 2018-2014
